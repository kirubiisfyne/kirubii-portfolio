# Media sources

Visual direction references Kirby Bilbao's main portfolio: <https://kirubiisfyne.github.io/>.

Game images come from Kirby's public itch.io project pages. Screenshots were resized to a maximum of 1600px and saved as JPEGs for web delivery. Their content is otherwise unchanged.

- `images/anii-cover.png` and `images/anii-01.jpg` through `images/anii-04.jpg`: <https://kirubiisfyne.itch.io/anii-grow-to-know>
- `images/kontexto-cover.png`: <https://kirubiisfyne.itch.io/kontexto>
- Gameplay trailer: <https://www.youtube.com/watch?v=xJZeUs_QqVA>

`ascii-field.svg` is an original decorative asset made for this site. No 3D models, poster artwork, or code from the main portfolio are bundled.
